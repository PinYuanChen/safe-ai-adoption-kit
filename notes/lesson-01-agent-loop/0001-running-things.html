uv run：專案專屬的魔法結界

一句話：在這個專案裡，跑任何 Python 東西前面都加 uv run。不加的話，你會跑到 macOS 內建、2021 年就退休的 Python 3.9。

背景

這台電腦上其實住著兩個 Python：系統內建的 3.9，跟 uv 幫專案下載的 3.12。anthropic 和 pytest 只裝在後者的「虛擬環境」（.venv/）裡。直接打 python 會叫醒錯的那個，然後它會一臉茫然地說找不到套件。

觀念

三個最常用的咒語

指令作用
uv run pytest跑全部測試
uv run pytest -v同上，但每個測試都報名字（比較有成就感）
uv run python打開 REPL，exit() 離開

REPL 是你的沙盒

不確定某行語法會發生什麼事？別猜，丟進 REPL 試。>>> 後面打什麼，它就立刻告訴你結果：

>>> import json
>>> orders = json.load(open("tests/fixtures/orders.json"))["orders"]
>>> len(orders)
9
>>> orders[0]["status"]
'shipped'

為什麼 import 得到 safe_ai_kit？

pyproject.toml 裡有一行 pythonpath = ["src", "tests"]，等於告訴 pytest：「找模組時也去 src/ 和 tests/ 看看」。但這個設定只對 pytest 有效。自己在 REPL 裡 import 要這樣開：

PYTHONPATH=src uv run python

踩雷紀錄

ModuleNotFoundError: No module named 'safe_ai_kit'
在 pytest 外面跑，忘了 PYTHONPATH=src。
