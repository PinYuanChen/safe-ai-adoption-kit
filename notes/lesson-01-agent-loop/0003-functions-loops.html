函式、迴圈、一行寫完的 list

一句話：Python 用縮排代替大括號。縮排就是文法，不是美觀問題，空格數錯了程式就會錯。

背景

寫 lookup_order 和 run_agent 需要的語法其實不多：函式、for、if，再加上一個讓人第一眼看不懂的 list comprehension。

觀念

縮排 = 誰歸誰管

函式

def lookup_order(order_id: str, orders: list[dict]) -> dict:
    for order in orders:
        if order["order_id"] == order_id:
            return order                 # 找到就立刻收工，後面不跑
    return {"error": "Order not found", "order_id": order_id}
  • order_id: str 是型別標註。它只是給人看的備忘錄，Python 執行時完全不會檢查。傳數字進去它也照收不誤。
  • -> dict：這個函式承諾回傳 dict。
  • return = 下班打卡，函式立刻結束。

for、if、elif

for turn in range(MAX_TURNS):     # turn 依序是 0, 1, 2, 3, 4
    if response.stop_reason == "end_turn":   # 比較用兩個等號
        return ...
    elif response.stop_reason == "tool_use": # else if 在 Python 叫 elif
        ...
    else:
        raise ...
raise AgentLoopError("max turns")   # 迴圈跑完都沒 return，才走到這裡

最後一行是 run_agent 的保險絲：迴圈跑滿 5 輪還沒拿到答案，就大聲報錯，不讓它無限跑下去燒錢。

List comprehension：把 4 行壓成 1 行

等同於這段比較囉嗦的寫法：

texts = []
for block in response.content:
    if block.type == "text":
        texts.append(block.text)

字串三招

f"turn {turn + 1}"        # f-string：大括號裡放變數或算式
"\n".join(texts)          # 用換行把一串字串黏起來
"Let me check" in answer  # 有沒有包含這段字？回傳 True / False

踩雷紀錄

IndentationError
空格和 Tab 混用，或少縮一格。編輯器設成「Tab 自動轉 4 個空格」就沒事了。
