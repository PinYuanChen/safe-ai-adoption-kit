筆記

Python 語法（寫的時候卡住的）

  • 0001
    uv run：專案專屬的魔法結界為什麼直接打 python 會找不到套件、REPL 怎麼玩
  • 0002
    dict、list，以及「點」和「中括號」之爭模型回的是物件、你送的是 dict
  • 0003
    函式、迴圈、一行寫完的 list縮排、for、list comprehension、f-string
  • 0004
    出錯的時候：raise 還是回傳錯誤？None、isinstance、.get()，以及什麼時候該大聲失敗
  • 0005
    pytest 生存指南fixture、pytest.raises、收集錯誤、先紅後綠

元件與協作（看不懂它們怎麼串起來的）

  • 0006
    Agent loop：一場你來我往的對話模型不會自己跑工具，它只會「點餐」
  • 0007
    messages 是怎麼長大的模型沒有記憶，每次都要重講一遍
  • 0008
    解剖室：response、tool 定義、tool_result每個東西裡面到底裝了什麼
  • 0009
    FakeClient：你是導演，它是照劇本念台詞的演員FakeMessage、reply、client.calls 的關係
  • 0010
    測試地圖與待辦每個測試在保護什麼，以及之後要回頭想的事
